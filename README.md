A [make.fun](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) entry for the
bounty "Everyday Wonder, Two Days to Find the Line". The program writes
one sentence — a small moment of wonder in everyday life — to
`/output/entry.txt`.

> The kettle clicked off a second before I reached for it, as if the
> kitchen had been listening to me all along.

Run it with Node 22:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

No network, no randomness: two runs write identical bytes.
